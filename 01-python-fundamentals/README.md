# Python Fundamentals

This section documents the foundational Python concepts required for Business Intelligence, Data Analysis and Data Engineering.

## Lessons

### Lesson 01 – Python Introduction
- Python environment setup
- Anaconda and JupyterLab
- Executing Python code

### Lesson 02 – Variables and Data Types
- Variables and assignments
- Strings, integers, floats and Boolean values
- Arithmetic and comparison operators
- Type conversion
- Practical financial calculations

### Lesson 03 – Python Data Structures
- Lists
- Tuples
- Dictionaries
- Sets
- Nested data structures
- Working with business records

## Practical Applications

The exercises focus on business scenarios such as:
- Employee information
- Product catalogues
- Sales calculations
- Customer records
- Transaction data

## Learning Objective

Develop a strong Python foundation that can be applied to data analysis, data cleaning, data transformation and ETL development.
